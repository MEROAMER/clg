## Image Negative
f′(x, y)neg = (L − 1) − f(x, y)original

### How to solve?
- حرفيًا بقلب الأبيض أسود والعكس، هعمل دا إزاي؟ هجيب ال negative بتاعهم => يعني القيمة إللي كانوا هياخدوها لو مشوا بالعكس => بطرحهم من 255.
- لو عاطيني RANGE معين بقا؟ L=2^q 
- (q=No. of bits. if q=8, then L=28 =256)*

## Contrast Stretching & Contraction
- Dynamic Range: the range in which image details exist.
- we wanna INCREASE that range -> increasing contrast -> increase difference between elements -> expand intensity range.
- making the white whiter & dark darker.
- works best for: low contrast, narrow range of intensities.

### How to solve?
#### 1. Stretching
![](media/Pasted%20image%2020251021050217.png)

- دلوقتي عندي علاقة خطية بين الدالة قبل تحسينها والدالة بعد تحسينها، كل واحدة بال x, y بتوعها -> f = dynamic range.
- عايزين نجيب العلاقة بينهم في مدى الألوان بتاعي 255.
- طيب دلوقتي التغيّر في العلاقة دي مش ثابت/كتير -> هعتبر كل واحدة منهم علاقة لوحدها وأجيب معادلتها منفصلة وحدودها منفصلين.
- عندي رقمين مهمين، ال dynamic range دا ليه نقطة بداية ونهاية، بسمّيهم r1, r2 ->r1= أصغر قيمة في الgray levels || r2 = أكبر قيمة في ال gray levels.
- عايزة أفرد الخط دا لحد ما يوصل بدل r1, r2 => S1, S2.
- هقسم العلاقة بتاعتي حسب النقط المهمة دي:


1. الخط الأول: 0 -> r1
	- معادلة الخط دا = قيمة ال X * الميل m
	- f′(x, y) = f(x, y) * m
	- لأن ال X عندي هنا هي ال f = dynamic range.


2. الخط التاني: r1 -> r2
	- عندي هنا جزء مقطوع من محور ال y (إللي عملتله معادلته في الأول) مش عايزينه يدخل في الحسابات معانا، ف هنلغيه في المعادلة بإننا نطرح آخر قيمة في X * الميل الحالي بتاعي، وهزود آخر قيمة في ال y بتاعته S1.
	
		- ليه؟ لأن المعادلة y = mx، والتانية y2 = mx2
		- y2 - y1 = mx2 - mx 
		- y2 = mx2 - mx + y1
		- هعوض بقيمة ال x, y بتوع الخط القديم S1, r1 هتطلعلي المعادلة دي.

	- الميل = فرق الصادات / فرق السينات.
	- ![](media/Pasted%20image%2020251021051344.png)


3. الأخير: r2 -> (L-1) aka 255:
	- نفس التانية بالظبط، بس آخر قيمة في الصادات عندي = L-1 = 255.
	- ![](media/Pasted%20image%2020251021051732.png)


#### 2. Contraction:
- نفس ال stretching بس هبدل ال r1, r2 => S1, S2.

## Bit Plane Slicing
![](media/Pasted%20image%2020251027132554.png)
- دلوقتي أنا الصورة عندي متكونة من 8-bit من 0 -> 7
- كل bit عبارة عن binary pixel block زي شبكة من المربعات البيكسلز إللي بتحمل قيمة binary 
- ال blocks دول بيترصوا فوق بعض علشان يكونوا الصورة الكاملة 8-bits
- لو حطيت قيمة plane 7 تساوي 0 => هتكون سودا جدًا (اعتبرها ال 0 بتاع ال gray levels)
-  لو حطيت قيمة plane 7 تساوي 1 => هتكون بيضا جدًا (اعتبرها ال 255 بتاع ال gray levels)

## Histogram Equalization
- دلوقتي عندي صورة، الهيستوجرام بتاعها متوزع على range معين من ال gray values مش واخد من 0-255 لأن الصور العادية مبتاخدش الرينج كله
- الصورة دي هيكون ليها إحتمالات لتواجدها في الرينج بتاعنا 0 - 255:
	1. 0 - 100/130: صورة غامقة 
	2. 130/170 - 255: صورة فاتحة
- بنعتمد كمان على ال STD/variance (التباين/بُعد قيم البيكسلز عن بعضهم/الرينج إللي متفرقين عليه) بتاع الصورة:
	- STD(variance) -> HIGH = HIGH CONTRAST
	- STD(variance) -> LOW = LOW CONTRAST
![](media/Pasted%20image%2020251027135027.png)

- طيب عايزين نعمل إيه بردو؟ عايزين الصورة متكونش محشورة في رينج صغير
	- (variance صغير مش هتكون تفاصيلها واضحة) 
	- (موجودة بين رينج غامق كله أو فاتح كله = مش واضحة بردو)

- اسمه إيه الرينج بتاع أي صورة؟ Dynamic Range
- هنعمل فيه إيه؟ 
	- هناخده لو محشور في رينج صغير(100-200) مثلاً => هنفرده على ال 0-255 بتاعتنا (إلا لو هو محددلي رينج أفرده عليه)
	- لو مفرود على رينج كبير جدًا => هنصغر ال Dynamic range بتاعه لرينج معين هيديهولي.

### How to solve?

- عندنا رموز مهمة:
	- الهيستوجرام العادي بتاعنا: كنا بنجيب لكل قيمة : اتكررت كام مرة
	- h(r) = n => histogram of gray value(r) = (n) times
	- ![](media/Pasted%20image%2020251027134722.png)

- الهيستوجرام المعدَّل(Normalized): بجيب لكل gray value(r) الـ probability 
- بمعنى: كل قيمة r موجودة كام مرة في نطاق فضاء العينة بتاعتي أو ال sample space (إللي هي الصورة بتاعتي = مساحة الصورة = M×N)
- ![](media/Pasted%20image%2020251027135000.png)

![](media/Pasted%20image%2020251027135204.png)
- عايزين نعمل إيه؟ نحوّل الهيستوجرام العشوائي بتاعنا p(r) لهيستوجرام مظبوط(normalized) <= p(s)
- هعملها إزاي؟ أنا اوريدي جبت ال p(r) إللي هي احتمال وجود قيمة ال r في فضاء الصورة (M×N)
- إيه هي ال p(s)؟ = CDF cumulative distributed function
- بمعنى: أنا الصورة بتاعتي كل بيكسل متصل باللي قبله/بعده، ف بجيب ال distribution على أنه cumulative كأني ببني كل بيكسل على إللي قبلها
- بجيبها إزاي؟ 
	1. بجيب ال cumulative بتاع كل بيكسل(قيمة ال p(r) + كل قيم ال p(r) إللي قبلها)
	2. باخد كل cumulative لكل بيكسل وبضربه في ال range إللي عايزني أوزعه عليه => ممكن يكون 255 أو رينج معين عاطيهولي في المسألة
		1. الرينج إللي بيديهولي بيبقا ليه بداية ونهاية => بجيب (نهاية-بداية) => هو دا الرقم إللي بضربه في ال cumulative 
	3. كدا جبت ال new gray value => بس أنا عندي رينج معين عاطيلي بدايته، مفروض أبدأ من بعد البداية وأوصل قبل النهاية صح؟ => إذن هجيب ال gray value بتاعتي إللي لازم تكون أكبر من البداية => هجمع عليها قيمة gray value بتاع البداية علشان تبدأ من بعدها
	4. الحمدللههههه كدا معانا gray value:
		1. محشورة بين البداية والنهاية الجداد
		2. normalized 

- مهم نخلي بالنا الرينج اللي عاطيهولي هل full range(0-255) ولا رينج معين
